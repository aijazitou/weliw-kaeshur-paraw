# ؤ لِو کٲشُر پَرٛو

A book for learning to read and write Kashmiri in the
Arabic (Perso-Arabic) script, for learners of all ages,
with hand-drawn pictures.

**Status: work in progress.** Sections are still being written
and may change.

Page size: 7 x 10 inches, written as web pages (HTML and CSS)
and printed to PDF.
